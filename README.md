# PFO1 - Francisco Luis

Este proyecto es mi portafolio personal creado para la materia Front End. Es una página web diseñada para presentar quién soy, cuáles son mis habilidades tecnológicas y cómo pueden contactarme.

## 🛠️ Tecnologías Utilizadas
- **HTML5**: Estructura semántica del sitio.
- **CSS3**: Estilos personalizados, diseño adaptativo y efectos visuales.
- **JavaScript**: Interactividad de la interfaz.

## 🧠 Decisiones de Diseño y Desarrollo
- **Enfoque Visual**: Se optó por una estética moderna de tipo "terminal/tecnológica" con tonos oscuros y detalles en colores destacados para reflejar el perfil de desarrollo de software.
- **Estructura Modular**: Se organizaron los componentes de forma limpia en secciones (Inicio, Sobre mí, Proyectos, Habilidades y Contacto) para facilitar la lectura del usuario y del evaluador.
- **Adaptabilidad**: Se ajustaron las dimensiones, márgenes y la posición de la imagen de perfil de manera minuciosa mediante iteraciones de código para garantizar una correcta visualización en distintas resoluciones.

## 🤖 Asistencia de Inteligencia Artificial
Durante el desarrollo del proyecto se utilizó **Gemini** como asistente de colaboración técnica para:
- La resolución de problemas de maquetación y centrado de elementos en CSS.
- La estructuración y redacción del código base.
- El asesoramiento en el despliegue del sitio en plataformas de producción.
